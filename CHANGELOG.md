# Changelog

Versions are numbered 0.0.0.1, 0.0.0.2, 0.0.0.3 ... - each release is exactly one higher than the previous one.

## 0.0.0.2 - unreleased

- Smart shapes: rough circles, boxes, triangles, diamonds, lines and arrows become clean shapes (a V after a line makes an arrow); connectors snap onto shapes; Undo restores freehand.
- Record a lesson: screen or area, drawings, pointer and microphone to MP4, with pause.
- Pages on the whiteboard, PDF handouts, save and reopen drawings (.inkit).
- Drawings follow PowerPoint slides; show the screen, an area or a window on a second screen.
- Focus box, stamps (tick, cross, ?, !, star), sticky notes, handwriting to text.
- Quick keys (1-6 colours, [ ] thickness), right-click tool wheel, two/three-finger tap undo/redo, a shortcut for any feature, inkit:// links.
- First-run tour, Settings > About & Feedback, send feedback with the version filled in, optional update check, start with Windows, crash reports.

## 0.0.0.1 - 2026-09-26

First public test release.

- New look: dark toolbar (light theme available) with the InkIt logo, tools grouped Draw | Add | Present | Edit | Find, pen right after the pointer.
- Zoom into an area: drag a box; it fills the screen and stays put so you can draw on it. Follow-the-mouse zoom is still available.
- Screenshot of an area: copied to the clipboard at once; save as PNG/JPG from the preview.
- 15 pen styles, highlighter, shapes, text, step numbers, laser pointer, spotlight, whiteboard/blackboard/grid boards.
- Select drawings to move, recolour, copy or delete; Undo also restores Clear.
- Search every feature with Ctrl+K; browse them all with F10.
- Plain-language tooltips, settings and messages; version shown in Settings and the tray.
