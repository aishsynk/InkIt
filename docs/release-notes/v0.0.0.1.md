**First public test release of InkIt** - thank you for trying it!

### What to try
- **Pen** (P): draw over any app. Press **Esc** to get your mouse back.
- **Zoom into an area** (Ctrl+Shift+5): drag a box around something small; it fills the screen and stays put. Draw on it, then press Esc.
- **Screenshot of an area** (Ctrl+Shift+4): drag a box, then paste straight into Teams, PowerPoint or email with Ctrl+V.
- **Laser** and **Spotlight** while presenting; **Whiteboard** for a clean space.
- **Search** (Ctrl+K): type what you want to do.

### Highlights
- Tools grouped Draw | Add | Present | Edit | Find, with the pen right after the pointer.
- New InkIt logo and app icon; dark theme by default, light theme in Settings.
- Plain-language tooltips and settings.
